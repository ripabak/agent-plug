How to use

Open this page with the agent id and token as query parameters — exactly like the data-* attributes of the embed snippet:

/demo.html?agent=1&token=YOUR_PUBLIC_TOKEN&base=http://localhost:8000

Optional theming: theme selects a preset (indigo|emerald|rose|amber|slate|ocean) and any color token can be overridden, e.g. &headerBg=%23dc2626&btnBg=%23dc2626. The Embed tab in your dashboard links here automatically. Then look at the bottom-right corner 👉
